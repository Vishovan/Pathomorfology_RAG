# Pathology RAG: Мультимодальный ассистент патоморфолога и консультант по ГОСТам

Мультимодальная справочно-информационная RAG-система на базе **LangGraph** и **LlamaIndex**.

Система разработана для внутреннего использования врачами-патологоанатомами, ординаторами, биологами и разработчиками медицинских систем.

---

## 🎯 Основной функционал

### 1. 🔬 Патоморфологический RAG (все нозологии, фокус — РМЖ и ИГХ)
- **Рак молочной железы (РМЖ):**
  - **HER2/neu (ERBB2):** алгоритм оценки ASCO/CAP (2018/2023) и клинических рекомендаций Минздрава РФ. Градации 0, 1+ (HER2-low), 2+ (неопределенный / equivocal) и 3+ (позитивный). Алгоритм подтверждающего тестирования методом гибридизации in situ (**FISH / SISH**): соотношение HER2/CEP17 >= 2.0 и копийность >= 4.0/6.0.
  - **Ki-67 (индекс пролиферации):** правила подсчета (не менее 500–1000 клеток в зонах hot spot), клинические пороги (< 14–20% vs >= 20%), суррогатная классификация молекулярных подтипов (Люминальный А, Люминальный В HER2-, Люминальный В HER2+, HER2-обогащенный, Тройной негативный).
  - **Рецепторы эстрогена (ER) и прогестерона (PR):** порог позитивности 1%, шкала Allred (0–8 баллов).
  - **Гистологическая градация по Ноттингемской системе** (Nottingham Histologic Score / Bloom-Richardson-Elston: тубулообразование, ядерный полиморфизм, митозы).
  - **Дифференциальная диагностика:** инвазивная карцинома NST vs инвазивная дольковая карцинома (ILC, утрата мембранного **E-cadherin**).
- **Общая патоморфология:**
  - Крупозная пневмония (стадии прилива, красного опеченения, серого опеченения, разрешения).
  - Стеатоз печени (макро- и микровезикулярный, окраска Судан III).
  - Атеросклероз (стадии липоидоза, липосклероза, атероматоза, осложненных поражений).
  - Туберкулез легких (казеозный некроз, эпителиоидноклеточные гранулемы с клетками Пирогова-Лангханса, Циль-Нильсен).
  - Колоректальная аденокарцинома (тубулярная, муцинозная, MMR/MSI статус, KRAS/NRAS/BRAF).

### 2. 🖼️ Поиск микропрепаратов и интеграция с Whole Slide Images (WSI)
- Поиск по тексту, диагнозу, органу, окраске (`H&E`, `ИГХ Ki-67`, `ИГХ HER2`, `Судан III`, `Циль-Нильсен`) и увеличению (`100x`, `200x`, `400x`).
- Выдача карточек препаратов с подробным микроскопическим описанием и **прямыми глубокими ссылками на цифровой просмотр слайда (WSI deep links)** в сервисах PathPresenter, WebPath (Utah), HistopathologyAtlas, Leeds Virtual Microscopy, hist.ysmu.ru, path-anatomy.ru.

### 3. ⚖️ Режим юриста: Регуляторика и ГОСТы РФ для медицинского ПО
- **Разграничение трех самостоятельных направлений регистрации в РФ:**
  1. **Роспатент:** регистрация программы для ЭВМ, свидетельство о госрегистрации, фиксация авторских прав на код;
  2. **Минцифры России:** включение в Единый реестр отечественного ПО (ПП РФ № 1236, льготы по НДС, допуск к госзакупкам по 44-ФЗ/223-ФЗ);
  3. **Росздравнадзор:** регистрация ПО как медицинского изделия (SaMD) с получением Регистрационного удостоверения (РУ).
- **Квалификация системы и стратегия ТЗ (Non-SaMD статус):**
  - Подробное юридическое обоснование, почему Pathology RAG **НЕ подлежит регистрации как медизделие**: справочно-образовательный статус, отсутствие обработки персональных данных пациентов и отсутствие автоматической постановки диагноза.
- **Полная база стандартов ГОСТ:**
  - *Проектирование и разработка:* ГОСТ 34.602-2020 (ТЗ на АС), ГОСТ Р 59793-2021 (Стадии создания АС), ГОСТ 34.201-2020 (Виды и комплектность документов), ГОСТ Р 59795-2021 (Требования к содержанию документов), ГОСТ Р 59792-2021 (Испытания АС).
  - *Жизненный цикл и качество:* ГОСТ Р ИСО/МЭК 12207-2010 (Процессы ЖЦ ПО), ГОСТ Р ИСО/МЭК 25010-2015 (Модели качества SQuaRE).
  - *Безопасность и медицинские данные:* ГОСТ Р 56939-2024 (Безопасная разработка ПО), ГОСТ Р 52636-2006 (Электронная история болезни), ГОСТ Р 56849-2015 (Безопасность медицинского ПО), ГОСТ Р 51583-2014 (АС в защищенном исполнении), ГОСТ Р ИСО/МЭК 27001-2021 (СМИБ).

### 4. 🌐 Внешний поиск и научная литература
- Интеграция с **PubMed API (NCBI E-utilities)** для поиска рецензируемых статей.
- Поиск препринтов в **arXiv** и **bioRxiv**.
- Поиск в открытом интернете через DuckDuckGo Search.

          ┌────────────────┼────────────────┬────────────────┐
          ▼                ▼                ▼                ▼
   [ РМЖ / Патология ]  [ Поиск фото ]   [ Режим юриста ] [ Внешний поиск ]
   retrieve_pathology   image_search    legal_consultant literature_search
          │                │                │                │

   grade_documents         │                │                │
    (Corrective RAG)       │                │                │

Релевантно    Недостаточно │                │                │
   │             ▼         │                │                │

                 │

         generate_answer (Синтез цитат, микропрепаратов и дисклеймеров)

## 🚀 Быстрый старт

### 1. Установка окружения

```bash
# Создание и активация виртуального окружения
python3.11 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск интерактивного Веб-интерфейса

```bash
python scripts/run_ui.py --port 8000
```
После запуска откройте в браузере: **http://127.0.0.1:8000**
В интерфейсе доступны:
- Переключение режимов: *Авто-роутер*, *РМЖ: ИГХ*, *Общая патология*, *Микропрепараты*, *Режим юриста*, *PubMed*;
- Быстрые кнопки примеров запросов;
- Карточки микропрепаратов с кнопкой перехода в цифровой WSI-просмотрщик;
- Ссылки на цитируемые источники и нормативные документы.

### 3. Запуск терминального чата (CLI)

```bash
python scripts/agent_chat.py
# или с принудительным режимом:
python scripts/agent_chat.py --mode legal
```

### 4. Запуск тестов и бенчмарка

```bash
# Запуск юнит-тестов (22 теста)
pytest tests/

# Запуск бенчмарка качества ответов агента
python scripts/eval_benchmark.py
```
