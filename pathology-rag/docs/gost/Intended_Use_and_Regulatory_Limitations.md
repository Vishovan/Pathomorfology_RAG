# НАЗНАЧЕНИЕ, ОГРАНИЧЕНИЯ И РЕГУЛЯТОРНЫЙ СТАТУС СИСТЕМЫ
## Обоснование неприменимости требований к медицинским изделиям (Non-SaMD)
### Документ: АС-ПАТ-RAG.НО

---

### 1. ЮРИДИЧЕСКАЯ И РЕГУЛЯТОРНАЯ КВАЛИФИКАЦИЯ

В соответствии с частью 1 статьи 38 Федерального закона от 21.11.2011 № 323-ФЗ «Об основах охраны здоровья граждан в Российской Федерации» и Решением Коллегии Евразийской экономической комиссии от 22.12.2015 № 173 (в ред. Решения № 46):

> Программное обеспечение относится к медицинским изделиям (**SaMD — Software as a Medical Device**) только в том случае, если оно предназначено производителем для применения в медицинских целях: профилактики, диагностики, лечения, медицинской реабилитации заболеваний, мониторинга состояния организма человека, проведения медицинских исследований.

#### 2. ПОЧЕМУ «PATHOLOGY RAG» НЕ ЯВЛЯЕТСЯ МЕДИЦИНСКИМ ИЗДЕЛИЕМ?

| Критерий регулятора (Росздравнадзор / ЕАЭС) | Медицинское изделие (SaMD) | Система «Pathology RAG» |
| :--- | :--- | :--- |
| **Обработка данных конкретного пациента** | Анализирует персональные снимки, стёкла WSI, результаты анализов пациента | **ЗАПРЕЩЕНО.** Система обрабатывает только обезличенную литературу, опубликованные учебники и общедоступные атласы |
| **Формулирование диагноза** | Автоматически выдает клинический или патологоанатомический диагноз по конкретному случаю | **ОТСУТСТВУЕТ.** Предоставляет цитаты из классификаций и справочные критерии |
| **Влияние на врачебное решение** | Формирует директивные рекомендации по выбору протокола лечения пациента | **ИСКЛЮЧЕНО.** Является исследовательской поисковой системой (RAG) |
| **Пользователь** | Пациент или лечащий врач в процессе оказания медпомощи | Специалист-исследователь, патоморфолог, преподаватель, ординатор, студент |

### 3. ОБЯЗАТЕЛЬНЫЕ ДИСКЛЕЙМЕРЫ (ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ)

В соответствии с требованиями стандартов качества ПО (ГОСТ Р ИСО/МЭК 25010-2015) и рекомендациями Росздравнадзора:

#### 3.1. Дисклеймер в интерфейсе (User Interface Disclaimer)
При каждом запуске системы и под каждым ответом отображается следующее предупреждение:

```
⚠️ ВНИМАНИЕ: Справочно-образовательная система для специалистов в области патоморфологии.
Информация получена методом семантического поиска по открытым руководствам, учебникам и базам данных.
Система НЕ является медицинским изделием, НЕ выполняет медицинскую диагностику и НЕ может использоваться
для назначения лечения или интерпретации анализов конкретных пациентов. Окончательное решение принимает
исключительно сертифицированный врач-патологоанатом.
```

#### 3.2. Дисклеймер в юридическом режиме
```
⚖️ Справка по ГОСТам и нормативным документам носит консультационно-информационный характер.
При прохождении официальных регистрационных процедур в Роспатенте, Минцифры и Росздравнадзоре
требуется привлечение юридической службы организации и профильных аккредитованных экспертов.
```

### 4. ЗАКЛЮЧЕНИЕ ЮРИСТА ПО ПРОЕКТУ

1. В текущей конфигурации система «Pathology RAG» полностью квалифицируется как **информационно-поисковая и образовательная база данных** (код ОКПД2 58.29.32 / 62.01.29).
2. Государственная регистрация в качестве медицинского изделия в Росздравнадзоре **НЕ ТРЕБУЕТСЯ**.
3. Для защиты интеллектуальной собственности рекомендуется:
   - Оформить Свидетельство о государственной регистрации программы для ЭВМ в **Роспатенте**;
   - При необходимости коммерциализации подать заявление в Реестр отечественного ПО **Минцифры России** для освобождения от НДС (ст. 149 НК РФ).
